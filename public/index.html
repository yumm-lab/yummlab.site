Why a kitchen

Side projects get messy. The tools shouldn't.

We kept rebuilding the same setups, retyping the same prompts and re-explaining how we work to coding agents. yumm lab is where we fix those things once, together.

  • Same setup, every machine

    A new laptop shouldn't cost a day of config.

  • Agents that forget

    Write our conventions down once, so agents follow them every time.

  • Steps on repeat

    If we've done it three times, it becomes a helper.

  • Ideas with nowhere to go

    A shared place to try things, without a roadmap.

Not a startup. Just a kitchen.

No roadmap, no deadlines. Just people who like making tools.

The recipe

A clear recipe for messy ideas.

No roadmap. Just four steps we repeat until something tastes right.

  1. 01

    Prep

    Someone gets annoyed by something. That's the idea.

  2. 02

    Cook

    Build the smallest thing that fixes it. Ugly is fine.

  3. 03

    Taste

    Use it ourselves for a few weeks. Keep it or bin it.

  4. 04

    Serve

    Clean it up, license it properly, open it to everyone.

What is yumm lab?

A GitHub organization where a small group of engineers keeps the side projects we build together. For now that means tooling for coding agents.

Can I use anything yet?

Not yet. Our first project is private while we tidy it up. It goes public on GitHub when it's ready to serve.

Why the kitchen thing?

Side projects behave like cooking. You start with what's in the fridge, taste as you go, and not every dish makes it to the table.

How do I keep up?

Follow the yumm-lab org on GitHub. You'll see the first public dish the day it lands.
